# Agroprognoza

Višemodelska vremenska prognoza za parcele: 8 meteoroloških modela (ECMWF, ICON, GFS, ARPEGE, UKMO, GEM, JMA, ECMWF AIFS) na jednom ekranu, pregled 10 dana, uslovi za prskanje, rizik od mraza, stanje zemljišta i vodni bilans.

Podaci: [Open-Meteo](https://open-meteo.com) (CC BY 4.0).
